# 职跃 CareerLeap — 服务器 Docker 部署

适合：一台装了 Docker 的 Linux 云服务器（Ubuntu / Debian / CentOS 等）。

## 1. 服务器准备

```bash
# 安装 Docker（Ubuntu 示例）
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
# 重新登录后再继续

docker --version
docker compose version
```

开放安全组 / 防火墙端口：**80**（必开），有域名做 HTTPS 再开 **443**。

## 2. 拉取代码

```bash
git clone https://github.com/Jasonwang-git/careerleap.git
cd careerleap
```

## 3. 配置环境变量

```bash
cp .env.production.example .env.production
nano .env.production   # 或 vim
```

至少改这几项：

| 变量 | 说明 |
|------|------|
| `POSTGRES_PASSWORD` | 数据库强密码 |
| `DATABASE_URL` | 密码与上面一致，主机名保持 `postgres` |
| `NEXT_PUBLIC_API_URL` | 浏览器访问地址，如 `http://1.2.3.4` 或 `https://你的域名`（**不要**写 `:8000`） |
| `CORS_ORIGINS` | 与上面相同 |

示例（仅 IP）：

```bash
POSTGRES_PASSWORD=MyStrongPass123
DATABASE_URL=postgresql://careerleap:MyStrongPass123@postgres:5432/careerleap
NEXT_PUBLIC_API_URL=http://1.2.3.4
CORS_ORIGINS=http://1.2.3.4
```

## 4. 一键启动

```bash
mkdir -p nginx/logs nginx/ssl
docker compose --env-file .env.production up -d --build
```

查看状态：

```bash
docker compose ps
docker compose logs -f --tail=100
```

浏览器打开：`http://你的服务器IP`

- 前端：`/`
- API：`/api/`
- 健康检查：`/health`

## 5. 常用运维

```bash
# 更新代码后重新构建
git pull
docker compose --env-file .env.production up -d --build

# 停止
docker compose --env-file .env.production down

# 只看后端日志
docker compose logs -f backend
```

## 6. 可选：域名 + HTTPS

1. 域名 A 记录指到服务器 IP  
2. 用 Let’s Encrypt 签证书（可用 certbot）  
3. 把证书放到 `nginx/ssl/`，再改 `nginx/nginx.conf` 增加 `listen 443 ssl`  
4. `.env.production` 里改成 `https://你的域名`

## 注意

- LLM Key 可在网页「设置」里配，不必写进服务器环境变量。  
- 原项目许可为非商业用途，商用需原作者授权。  
- 本机 Windows 开发仍用 `npm run dev` + `python main.py`，与服务器 Docker 互不影响。
